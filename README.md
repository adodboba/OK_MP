# Ozon Seller Sync

Интеграция с Ozon Seller API для 6 кабинетов: синхронизация номенклатуры, 
остатков, отправлений и построение дашборда.

## 🎯 Что делает проект

- **Номенклатура** — выгрузка товаров по 6 кабинетам с брендом, типом, комиссиями
- **Остатки** — FBO/FBS остатки по складам
- **Отправления** — ежедневный сбор заказов за вчера (FBS + FBO)
- **Дашборд** — 12 блоков аналитики: сводки, топы, риски остатков, новинки, география

## 🚀 Быстрый старт

### Требования
- Google-аккаунт с доступом к таблице
- API-ключи от Ozon Seller (Client-Id + Api-Key) для каждого кабинета

### Установка
1. Открой Google-таблицу → **Расширения → Apps Script**
2. Скопируй все `.gs` файлы из репозитория
3. Обнови `Config.gs` — вставь свои `clientId` и `apiKey`
4. `Ctrl+S` — сохранить
5. Обнови вкладку — появится меню **Ozon Sync**
