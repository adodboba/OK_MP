# Ozon Seller Sync

Интеграция с Ozon Seller API для 6 кабинетов: синхронизация номенклатуры, 
остатков, отправлений и построение дашборда.

## 🎯 Что делает проект

- **Номенклатура** — выгрузка товаров по 6 кабинетам с брендом, типом, комиссиями
- **Остатки** — FBO/FBS остатки по складам
- **Отправления** — ежедневный сбор заказов за вчера (FBS + FBO)
- **Дашборд** — 12 блоков аналитики: сводки, топы, риски остатков, новинки, география

## 🚀 Быстрый старт

### Требования
- Google-аккаунт с доступом к таблице
- API-ключи от Ozon Seller (Client-Id + Api-Key) для каждого кабинета

### Установка
1. Открой Google-таблицу → **Расширения → Apps Script**
2. Скопируй все `.gs` файлы из репозитория
3. Обнови `Config.gs` — вставь свои `clientId` и `apiKey`
4. `Ctrl+S` — сохранить
5. Обнови вкладку — появится меню **Ozon Sync**

### Первый запуск
Ozon Sync → 📊 Панель отчётов…
Выбери даты и кабинеты → «Собрать отправления» → «Пересобрать дашборд».

### Автоматизация
Ozon Sync → Установить триггер 9:00
Теперь `runDailySync` будет запускаться каждое утро:
- синхронизация номенклатуры
- синхронизация остатков
- сбор отправлений за вчера
- пересборка дашборда

## 📊 Дашборд

12 блоков на листе `_Dashboard`:

1. 📊 **Шапка** — дата отчёта и время обновления
2. 📦 **Сводка по кабинетам** — сумма, заказы, % FBO/FBS, отмены
3. 📈 **Сравнение** вчера vs позавчера — Δ суммы и заказов
4. 🏷️ **Сводка по брендам** — топ по сумме с локальными %
5. ⚠️ **Остатки под угрозой** (FBO) — 🔴 < 3 дн, 🟡 < 7 дн, 🟢 > 60 дн
6. 🏆 **Топ-20 SKU** по сумме
7. ❌ **Топ-20 SKU по отменам** — % отмен по каждому
8. 🌟 **Новинки** — первое появление за 7 дней
9. 🗺️ **География по кластерам** доставки
10. 🚚 **Локальность продаж** — % локальных + сводка по кластерам + направления
11. 📉 **Динамика за 7 дней** — сумма, средний чек, конверсия
12. 📅 **Динамика по дням недели** — средние продажи по Пн..Вс

### Подсветка в дашборде

- **% отмен** в сводках: 0% без цвета, 0–5% 🟡, ≥5% 🔴
- **% отмен** в топ-20: 0% без цвета, <35% 🔴, 35–65% 🟡, ≥65% 🟢
- **Флаги остатков**: 🔴🟡🟢 — фоны
- **Δ тренды**: рост 🟢, падение 0–20% 🟡, ≥20% 🔴

## 🎨 Особенности

- **Дашборд полностью перерисовывается** при каждом обновлении — нет накопления форматирования, старых Notes или условных правил.
- **Русский формат чисел** — проценты с запятой (`+14,8%`), суммы с разделителем тысяч.
- **Notes-подсказки** — наведи курсор на заголовок блока или колонки — увидишь формулу расчёта.
- **3 диаграммы**: столбчатая (кабинеты), круговая (гео), линия (динамика).

## ⚠️ Важные ограничения

- **6-минутный лимит** Apps Script — `runDailySync` укладывается, backfill за 30 дней может упасть
- **Лимит Ozon API**: 50 RPS на Client-Id
- **TZ скрипта** должна быть **Москва (GMT+03:00)** — иначе даты сдвинутся
